# БАШИСТ VPN (Android)

Минимальный Android-клиент WireGuard: одна кнопка подключения/отключения и импорт `.conf`.

## Важно
Приложение само по себе **не предоставляет сервер**. Для работы нужен действующий WireGuard-сервер в Германии и его клиентский `.conf` файл. Не публикуйте этот файл в GitHub: в нём находится приватный ключ.

## Сборка APK без компьютера
GitHub Actions workflow собирает debug APK при каждом push. После сборки откройте вкладку **Actions**, выберите последний запуск `Build Android APK`, затем скачайте артефакт `BASHISTVPN-debug-apk`.

## Использование
1. Установите APK.
2. Получите личный WireGuard `.conf` от своего сервера.
3. В приложении нажмите «Импортировать конфигурацию» и выберите файл.
4. Нажмите «ПОДКЛЮЧИТЬ» и разрешите Android создать VPN-подключение.

Не используйте чужие конфигурации и не публикуйте приватные ключи.
